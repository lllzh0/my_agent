# Changelog

## [Unreleased]

### Added

- `/resources` 可在空闲时开关工具、技能、指令和附加提示词，保存后无需重启；主菜单共用同一入口。

- 默认显示每条模型回复的平均 token/s 和首个输出等待时间，复用 OMP 原生统计条；轻量模式和恢复会话也生效。
- `/model` 管理显式模型连接，复用 OMP 模型目录与原生切换；连接密钥按地址和型号隔离，失败回退。
- `/new` 通过受控原生会话事务创建空白会话，保存旧记录并重置完整授权和临时许可。
- `/diff` 查看有界项目差异及覆盖清单；`/review` 复用 OMP 只读子任务运行器，限制请求数、时间并保存用量。
- `import_mcp_source` 将当前会话真实 MCP 调用结果导入来源，保留服务/工具/调用时间和覆盖信息；搜索摘要不能作为已读正文引用。

- `/goal` 复用 OMP 目标管理、预算和自动续跑，保持产品权限与计划边界；恢复会话后需人主动恢复目标。
- `/btw` 复用 OMP 旁问面板、追问及独立历史，不执行工具或改变主聊天。
- `/resume` 复用 OMP 原生选择器，恢复当前工作区旧会话；支持 ID 前缀，同时切换任务、来源、文件及撤销记录，重置临时授权。
- 可通过 /permissions 或 --permissions 选择手动、自动或本次完整授权；自动审核单独显示用量，异常判断转人工。
- grep/find 复用 OMP 原生搜索，支持正则、文件 glob、忽略规则、分页与不完整提示。
- read_source/search_source 支持按来源位置及 PDF 页码续读和检索，显示实际返回范围与提取限制。
- 开发命令可使用显式工具链目录、输出目录、环境变量名和单条 Git 元数据写授权。
- 统一产品命令帮助与补全，新增上下文、思考强度、本地用量、后台任务、任务进度及受控 MCP 快捷入口。
- `/redo` 可作为 `/retry` 的同义词，续接失败或中断的回答。
- `/undo` 可撤销最近一轮直接文件修改，保留聊天并通知模型；支持恢复原有文本、删除本轮新文件及重启后继续撤销。

### Changed

- 本地 main 同步已完成的单 agent 基础功能；协作保留在独立分支，尚未发布。
- 修改和资料记录改为 SQLite 按需读取及内容去重，不再因累计 100/200 条记录停止工作；旧 JSON 和来源 ID 保留。
- `/session` 仅开放信息查看，手动 `/compact` 使用摘要模式。
- 文件恢复菜单与 `/undo` 共用批准、计划模式、后台任务及文件冲突检查。

### Fixed

- 目标自动续跑和暂停恢复保留用户后来追加的授权限制；冷恢复补回审核任务说明。
- 交互入口启动原生输入循环，支持空闲时目标启动及自动续跑，关闭时取消输入等待。
- 以绝对文件路径开头的任务现在正常提交，不再被当作未知命令拦截；自动授权同步接收本次任务。
- 大批文件撤销及部分恢复后，模型收到的恢复通知覆盖全部实际恢复文件。
- 后台命令在等待批准时取消后不会继续启动；命令、文件和 MCP 在旧授权失效后不再开始执行。
- 自动审核保留长任务尾部约束，严格拒绝混合或异常标签，CLI 直接任务也传入审核上下文。
