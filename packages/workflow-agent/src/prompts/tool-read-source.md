Read another portion of an already stored source without refetching it. Use sourceId from read_document, web_fetch, import_mcp_source, or source listings. offset is a 1-based UTF-16 character position; limit is at most 12000. For a PDF, page selects a 1-based extracted page and offset is within that page. Follow range.nextOffset or range.nextPage. Check coverage for acquisition/extraction limits and range for the portion returned; never describe an excerpt as the whole original document.
