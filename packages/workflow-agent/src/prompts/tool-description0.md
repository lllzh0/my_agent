Run a managed command under the current human-selected permission mode. Use Windows PowerShell syntax on Windows and bash syntax on macOS; the system prompt identifies the platform. Normal/auto use the sandbox; full access does not. Background returns a task ID; use job_output to check it. gitWrite requests permission for one plain git command to write repository metadata; it cannot include shell operators or substitutions. Environment names, toolchain read roots and network domains come from user configuration. Cancel does not undo side effects.
