# 第一阶段日常功能

本页说明单 agent 主分支和协作分支共用的模型、新会话、差异审查、MCP 证据功能。多角色分配和团队预算仅在协作分支。没有加入第二阶段工作流预设。

## 模型连接

旧的 `model` 配置继续作为启动默认值。可在 `models` 数组添加候选，`key` 是 `/model` 使用的连接名称；省略时使用 `provider/id`。相同型号的不同连接必须给不同 key。密钥只写环境变量名，不保存值。

以下为配置片段，合并到已有 config.json；地址和型号需换成实际服务提供的内容：

```json
{
  "models": [
    {
      "key": "custom",
      "provider": "my-provider",
      "id": "my-model",
      "apiKeyEnv": "MY_MODEL_API_KEY",
      "api": "openai-completions",
      "baseUrl": "https://model.example.test/v1",
      "contextWindow": 65536,
      "maxTokens": 8192,
      "input": ["text"],
      "reasoning": false
    }
  ]
}
```

已收录模型复用 OMP 目录的能力和价格信息。未知模型必须显式填写 API、地址、上下文长度、最大输出和非空输入能力；未知价格不能当作免费。只有声明并支持思考能力的型号才接受相应强度。

- `/model` 查看候选、当前选择及凭据环境变量是否存在；存在不代表服务已认证成功。
- `/model custom` 切换连接；可追加当前模型支持的思考强度。
- 切换只作用于当前进程会话，不改配置。重启按配置默认模型开始；进程内 `/new` 和 `/resume` 保留当前模型。
- 正在回答、旁问、目标续跑、审查、后台任务或会话切换时拒绝切换。成功才清理临时授权；失败回退，无法回退时阻止继续请求，需重启。
- 自动授权审核器和只读审查使用各自冻结的连接和密钥，不回退到原生登录或其他环境变量中的密钥。

## 新建与恢复

`/new` 保存当前历史，使用原生会话切换事务打开新的空白记录。任务、来源、MCP 捕获结果、修改和撤销记录独立；旧文件本身不会回滚。通过 `/resume` 可返回旧会话。

当前模型、资源清单和计划/执行模式保留。manual/auto 按配置重新开始，full 和临时许可清除；旧目标不会自动继续。正在回答、旁问、目标执行、后台任务或其他切换时拒绝新建。切换前失败保留原会话；历史已提交但界面刷新失败时保留新记录，并提示重新打开。

## 查看和审查差异

`/diff` 展示暂存、未暂存和未跟踪文本的快照；`/diff HEAD` 或本地分支/提交查看工作区相对基准的差异。不拉取远端，不请求模型。自动收集范围限定在当前工作区，即使 full 也跳过凭据与产品状态目录。

通过 VCS 中央适配器读取路径、对象 ID 和文件模式，路径检查通过后才读取内容。不会执行 clean filter、textconv 或外部 diff，不写 Git 对象或索引。重命名以删除和新增展示。使用原始内容比较，不套用 Git attributes 的格式转换；这可能与普通 git diff 的展示不同。

单文件最多 128,000 字节，差异合计最多 96,000 字节、100 个文件，每类候选最多扫描 10,000 项。二进制、链接、子模块、冲突、大文件、路径限制和上限遗漏都会列出；部分未修改的受限文件也可能保守计为未覆盖。`complete: false` 表示不能声称检查完整。文件可被其他程序同时修改，快照不提供跨文件原子性。

`/review [本地基准]` 将同一快照交给当前模型，只提供 read/grep/find/ls，没有写入、命令、联网、MCP、团队工具和自动加载的项目资源。最多 6 次对话循环逻辑调用、120 秒；一次逻辑调用内部可能发生服务重试，因此不等于实际 HTTP 请求数。在接近上限时复用 OMP 的收尾机制。空差异不请求模型；超限、取消、失败或差异遗漏返回 partial。交互面板按 Esc 取消；用量保存在当前会话，`/usage` 的 codeReview 单列，不与主对话混算。token 和费用取自模型响应，费用只是估算。

## MCP 结果成为研究来源

在服务配置中为实际工具名设置 `researchTools`：

```json
{
  "researchTools": {
    "search_tool": "discovery",
    "fetch_document_tool": "content"
  }
}
```

`discovery` 表示搜索摘要，`content` 表示取得正文。分类由用户配置，模型不能通过工具参数把摘要升级为正文；未分类工具仍可照常调用，但结果不能导入。菜单目前不编辑这张分类表，修改后重启生效。

成功的 `mcp_call` 会返回当前会话捕获结果的 `resultId`。调用 `import_mcp_source({"resultId":"实际返回的ID"})` 导入，再用 `read_source`、`search_source`、`write_report`。入口不接受模型重新组织的正文或地址；伪造、跨会话、错误或取消结果不能导入。只记录服务实际提供的数据，不代表内容经过独立核实。discovery 来源不能作为已读事实引用。

结果携带服务、工具、调用时间、参数及内容摘要、保留范围和截断信息；已识别凭据在落盘前脱敏。只导入文本及结构化数据，不自动访问附件链接。每会话捕获最多 1000 条/20 MB，每次正文最多 200,000 字符，达到上限明确报告捕获失败，旧来源不会自动删除。同一捕获重复导入返回同一来源，不重跑 MCP 操作。混合返回的文字、嵌入文本和结构化 JSON 合并保存；非文本附件遗漏会使 `coverage.mcp.complete` 为 false。旧版本未保存的正文无法恢复，已导入的历史来源不被改写；旧捕获再次导入时会标明覆盖范围未验证。

## 本地验收

自动测试使用隔离临时目录、本机假模型 HTTP 服务和本机 MCP，不需要真实密钥。主分支运行：

```sh
cd packages/workflow-agent
bun test test
bun run check
```

人工试用可先 `/model` 查看、`/new` 后 `/resume` 返回，再在测试仓库编辑文件执行 `/diff`。`/review` 会产生真实模型请求，需自行选择服务后验证取消和结果质量。MCP 分类应以所使用服务的实际工具契约为准；不要将搜索摘要工具标为 content。自动测试通过不代表远端服务质量或真人终端体验已经验收。
