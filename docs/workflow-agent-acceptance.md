# 第一阶段真实任务验收

更新：2026-10-16。当前基础能力、离线测试和部分真实搜索链已有证据；以下六项任务仍待用户试用确认。配置文件、环境变量、手动 `--resume` 都是合格入口，不要求增加配置向导或恢复浏览器。

| 任务 | 状态 | 需要保留的证据 |
|---|---|---|
| 编程 1：修复有复现步骤的 bug | 待试用 | 复现、针对性检查通过、最终差异无无关修改 |
| 编程 2：保留人工修改，新增功能并运行长测试 | 待试用 | 原修改保留、任务/后台状态正确、取消能终止托管命令、直接文件恢复范围明确 |
| 编程 3：只读审查陌生项目 | 待试用 | 结论对应文件证据、没有项目写入 |
| 研究 1：比较技术方案 | 待试用 | 至少三份相关一手资料，结论、推断与引用可追溯 |
| 研究 2：网页与本地 PDF 综合 | 待试用 | 页码或片段位置，提取/截断/无法读取部分如实说明 |
| 研究 3：时间变化或来源冲突 | 待试用 | 区分事件与发布日期，保留冲突和未知部分 |

每项记录输入任务、使用模型/搜索服务、结果文件、运行检查、权限/取消行为、失败与用户反馈；不要记录密钥。单项失败不自动扩大为新功能开发，先复现原因和限制，再确定修复范围。

服务仍按用户选择使用 OpenCode Go / DeepSeek V4.1 Flash、Tavily；也可由用户明确选择已接入的 Exa MCP。真实搜索连通、本地假模型测试、自动检查和用户接受是不同证据，不能互相替代。

读取 probe.txt 后停顿的具体原因仍未确认，见 [调查](workflow-agent-read-stall.md)。跨平台、磁盘故障、OCR、OAuth、打包/GUI 不因当前底座具有相关能力而视为已完成。第一阶段整体结束仍需用户明确接受。
