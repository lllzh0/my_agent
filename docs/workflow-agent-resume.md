# 当前工作区会话恢复

日期：2026-10-17。底座 OMP 18.10.3，Bun 1.3.14，macOS arm64。

## 使用

在 `bun run agent --cwd /你的项目目录` 启动的终端中输入：

```text
/resume
```

上下键选择旧会话，Enter 恢复，Esc 取消；输入文字可以搜索。也支持 `/resume 完整会话ID` 或唯一 ID 前缀。当前会话 ID 可用 `/session` 查看。没有历史时显示提示，命令本身不请求模型。修改源码后需退出并重新启动产品才能使用新命令。

列表限于当前 `--home`、当前命名预设及当前工作区的产品会话，不扫描其他项目或原生 OMP 历史。工作区路径和已加载资源内容必须与旧会话匹配。启动时的 `--resume 会话文件` 继续可用，退出提示会显示当前实际打开会话的恢复命令。

## 恢复范围

- 聊天、任务进度、研究来源、文件修改与撤销记录一起切换。`/undo` 随后操作所恢复会话的文件记录；`/resume` 本身不改变项目文件，也不重跑工具。
- 保留当前模型连接配置和计划/执行模式。恢复成功后清除临时授权，授权方式按当前配置的 manual/auto 重新开始；不继承先前选择的 full。需要完整授权时由用户再次 `/permissions full`。
- 回答、压缩、重试、排队消息或后台任务未结束时拒绝切换。先按 Esc 等待回答停止，后台任务可用 `/jobs` 查看及停止。
- 切换前断开当前 MCP 连接，目标会话按需重新连接。失败前已断开的连接也需重新连接，不自动重放外部操作。
- 被其他进程占用、配置不匹配或无法读取的会话拒绝恢复，保留当前聊天。列表中过滤损坏/孤立的历史；不提供删除或跨项目跳转。
- 如果聊天已切换而后续界面刷新失败，仍完成任务、来源及撤销记录的切换并显示警告；显示异常时退出，用打印的 `--resume` 命令重新打开。

## 官方已有实现与本次适配

OMP 官方已经提供 [`/resume` 命令](https://github.com/can1357/oh-my-pi/blob/main/packages/coding-agent/src/slash-commands/builtin-lifecycle.ts) 和 [会话恢复控制器](https://github.com/can1357/oh-my-pi/blob/main/packages/coding-agent/src/modes/controllers/selector-controller.ts)。当前 checkout 也已包含这些能力，因此直接复用，无需引入第三方恢复插件或另写历史格式、选择器、全文搜索和历史切换引擎。

产品自己的任务、来源、撤销和诊断不在原生聊天文件内。此次新增 `runtime/sessions.ts` 协调原生切换和产品记录，`runtime/session-state.ts` 复用初始化/关闭逻辑。工具始终从当前 state 获取记录对象，避免恢复后继续写入上一会话。

底座仅增加可选的宿主接口：TUI 恢复保留当前模型配置、退出时动态生成恢复命令、在产品状态切换/关闭期间拒绝新的提示和重试。选择器按宿主提供的能力显示删除与跨项目提示。未设置这些选项时保留原生行为，没有新增依赖。

会话切换期间保持源/目标独占写入，退出等待切换结束后关闭最终记录。原生已成功切换后，即使重画界面失败，也继续完成产品记录绑定，避免聊天与文件记录分离。
