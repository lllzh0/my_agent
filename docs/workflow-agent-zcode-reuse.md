# 外部技能导入与模型请求轨迹

这两项功能已接入 My Agent 的现有终端界面。外部技能需要逐个选择；请求正文需要手动开启记录。启动方式仍为 `bun run agent`，可加 `--demo` 使用本地固定回答。

## 选择并导入技能

1. 输入 `/resources`，选择“导入外部技能”。
2. 选常见来源中的一个目录、全部常见来源，或输入自定义目录的绝对路径。
3. 逐个选择技能；初始全部未选。“查看技能说明”显示完整名称、说明和来源路径。
4. “预览并继续”后选复制或软链接，确认“导入并启用”。

常见来源覆盖 Claude Code、Codex CLI、OpenCode、OpenClaw、Augment、Continue、Goose、Qwen Code、Qoder、Qoder CN、Windsurf、Trae、Trae CN、Kiro CLI、Roo Code、CodeBuddy，以及 `.agents/skills` 的用户/项目目录。扫描只读，不自动执行脚本或启用技能。

目标是 `<配置目录>/skills/<来源目录名>`；默认配置目录是 `~/.my-agent-omp`。只将选中的 `SKILL.md` 加入资源配置，参考文件、脚本等一并保留。空闲时成功导入后立即启用；同名技能或同目标目录一律跳过，原文件不覆盖。结果分别显示已导入、跳过和失败。

复制得到独立副本；软链接持续使用来源，来源被移动或删除会使它失效。来源正文变化后要 `/resources reload` 或重启重新加载；恢复旧会话仍遵守原有资源签名检查。技能关闭用资源菜单或 `/resources off skill:名称`，重新开启用 `/resources on skill:名称`。关闭不会删除文件。

手动调用：在终端输入 `$brainstorming 你的需求`。输入 `$` 可补全当前启用的技能；输入 `/` 只显示普通命令。旧 `/skill:brainstorming` 会提示改用新写法。启动时请等到“输入已就绪”，提前到达的按键不会执行。

导入期间阻止新模型任务及冲突的资源切换；已有模型回答、旁问、后台任务或目标模式运行时先等待结束。取消或启用失败会撤回本次创建的目标，不改变其他技能。复制文件不执行安装脚本；技能依赖的外部程序仍需原本就能使用。

边界：每次扫描最多 10000 项、8 层目录，支持 `.system`，跳过隐藏缓存和常见构建目录；单个技能至多 50MB、10000 项、32 层，`SKILL.md` 至多 1MB。无效元信息、越过来源根的目录链接、悬空/循环链接和非常规文件会报告或拒绝。普通外部扫描不会跟随来源根以外的符号链接；可把实际来源目录作为自定义扫描根。

启用技能后允许读取其参考文件；复制到应用目录的技能仅获窄范围读取例外，不能因此读取会话/配置，也不能修改托管技能。关闭后撤回该例外。既有工作区读取范围、显式用户读取范围和用户主动选择的完整授权模式保持原有含义。

## 记录、查看和比较请求

```text
/trace on
发送第一个问题
改变问题、模型或资源后发送第二个问题
/trace list
/trace show <请求ID>
/trace compare <请求A的ID> <请求B的ID>
/trace off
```

无参数 `/trace` 打开选择菜单，`/agent` 也有“模型请求轨迹”。列表给出完整 ID；可使用唯一前缀。查看和比较只读取已存在的记录，不重跑模型，不额外消耗模型额度。

开关默认关闭，仅当前进程有效，重启后不会自动开启。开启会记录之后开始的调用，不补录过去的聊天；运行中关闭会标记 `recording_stopped`，后续响应不保存，这不表示模型调用已经结束。关闭保留已有文件。

每条轨迹保存调用 ID、会话 ID、模型、主请求/旁路请求、起止时间、状态、供应商请求对象、已观察的 HTTP 状态，以及模型解析后的最终响应/工具调用/用量。后续请求中的工具结果可通过工具调用 ID 对照。

**捕获阶段是 `provider_payload_hook`**：从供应商发送前的 `onPayload` 接口读取真正构造的请求对象，保留其他请求钩子作出的修改，不从聊天记录猜造请求。个别供应商之后还有协议转换；传输内部重试、请求头和原始逐段响应不属于完整记录。覆盖本会话主请求和使用会话旁路的调用（包括旁问）；独立 `/review`、权限自动审核器及子代理未纳入。无正文捕获、截断或错误会明确标记。

差异按结构化 JSON 比较，忽略对象字段顺序、保留消息和工具数组顺序。显示“已记录字段相同”只说明保留部分相同；敏感字段、媒体和截断部分不能作完整请求相同的证据。

## 本地保存与边界

文件位于 `<配置目录>/state/<会话ID>/model-traces/<调用ID>.json`。只读取当前会话；新会话与恢复会话会切换对应目录。每会话保留最近 100 条，每条按实际文件大小限制为 256KiB；这是每会话上限，不是整个应用目录的总上限。

每次调用最多保留两次请求对象构造、16 个 HTTP 状态；正文有深度、节点和文本长度限制，超限会省略。文件使用现有原子保存与仅属主读写权限。磁盘写入失败只提示诊断缺失，不影响模型输出。

不记录请求头；常见凭据字段、环境中的密钥值、Bearer/sk 格式凭据会掩码；二进制、内嵌媒体和过长内容会省略。任意正文仍可能含代码、私人信息或未识别的凭据，不能把掩码视为完整脱敏。该功能不会主动上传轨迹；分享前自行检查。现有不含正文的 `model-stream.json` 异常摘要独立保留。
