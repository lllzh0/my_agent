## 可以直接使用的命令

在 fork 根目录：

```sh
bun run agent:prepare
bun run agent setup --defaults
bun run agent doctor
bun run agent --demo
bun run agent diagnose
bun run agent diagnose --output /已有目录/diagnostic.json
```

已经准备过的当前 checkout 可以直接运行 `bun run agent --demo`。真实模型在用户自己的终端设置 `OPENCODE_API_KEY` 后启动；没有真实密钥时，演示只证明流程能运行。退出后执行提示的完整 `--resume` 命令；同一会话被另一进程占用时，先关闭原进程。

Exa 配置及模型、资源选择见 [使用说明](../packages/workflow-agent/README.md)。配置文件和环境变量是本阶段认可的入口，不要求先做配置向导、会话浏览器或独立安装器。

## 实际验证

### Exa 与来源链

通过真实产品 `ManagedMcp` 批准连接 `https://mcp.exa.ai/mcp`，读取当时的工具 schema；使用 `web_search_exa`，传入 `query`、`objective` 与 `numResults: 3`。搜索 `site:bun.com/docs test runner documentation`，取得 Bun 官方测试文档链接。

产品 `Research.fetch` 随后读取 `https://bun.com/docs/test`，得到来源 S1、标题 `Test runner | Bun Docs`、9,721 字符的正文提取结果；报告样本使用该已读来源。这个样本验证来源链和保存规则，没有让真实模型比较资料，不代表研究质量验收，也不代表全文已读。

证据在父工作区 `artifacts/omp-delivery/exa-{catalog,search,source,verification}.json` 和 `exa-source-report.md`，可用 `validation/delivery/exa.ts` 复跑。没有搜索密钥、登录或付费调用；服务后续额度与可用性不由本地测试保证。

### 诊断和审查修复

诊断先验证错误分类与导出范围，再以真实宿主或 CLI 复现以下边界：

- 任意模型字段里的假令牌、私有路径和换行正文不会进入报告；仅导出静态目录认可的模型标识，未知值只显示未识别。
- 本地缺失文件 `401` 不会被当成 HTTP 鉴权失败；真实模型 HTTP 401 在会话记录和 CLI 提示中都归为鉴权失败。
- 会话目录超过 200 个后，恢复旧会话产生的新错误仍可选入近期报告。
- 损坏配置、诊断写盘失败、已有输出文件不会导致隐式修复、覆盖或改变原工具结果。

独立只读审查另复现并修复了：批准后等待沙箱或文件队列时切到计划模式仍执行、会话被另一进程占用时原生历史和产品记录分离、初始化失败遗留租约、脱离进程组的后代占用输出管道导致一直等待，以及未选坏子技能阻止单个有效技能启动。

命令现在在 spawn 前同步复查模式，文件工具在最终落盘前复查；已开始的操作不承诺撤销。产品宿主要求独占会话并禁止自动换历史身份，原生 OMP 的默认行为保持兼容。主命令退出后，残留输出管道最多再等待 1 秒；主动脱离原进程组的程序仍可能需要用户另行处理。

两个限定审查方向在修复后均返回无剩余发现。审查范围和自动测试不等同于安全证明、真实模型质量或人工验收。

### 干净源码安装

`validation/delivery/install.ts` 从 Git 可见的源码生成临时副本，不复制 `node_modules` 或 `.node` 文件；使用新建 HOME、空 Bun 缓存和独立临时目录。实际通过：

1. 按锁文件安装产品和工具视图生成器的依赖，不执行依赖安装脚本。
2. 生成工具视图，下载官方 18.10.3 原生组件，校验 SHA-512，验证加载后的组件版本。
3. setup、doctor、diagnose、首次离线回答与手动 `--resume`。
4. 同一历史保留两次提示；删除源码副本后，独立用户目录内配置和历史仍存在。

最终复跑从准备到恢复约 28 秒，具体步骤时间、退出码见父工作区 `artifacts/omp-delivery/source-install.json` 及 `install-*.log`。此时间只记录本机这一次运行，不是用户安装时长承诺。首次依赖安装和官方原生组件下载需要网络；不支持的平台或低于 Bun 1.3.14 会被前置检查拒绝，但未逐个平台或旧 Bun 实机验证。
