## 第一项：编辑审批

- `changes/preview.ts` 在完整文本或替换片段上计算差异，再使用中央截断工具限制展示，避免长前缀掩盖末尾实际修改。创建、覆盖、片段替换分开标明，显示新增/删除量；replace_all 的统计明确标为每个匹配片段。
- `operation-preview.ts` 供经典与墨线 UI 共用。审批选择器提供短摘要，只读详情保留差异头部；不完整预览明确提示。查看/关闭详情不授权，返回后仍需作出决定，取消视为拒绝。
- 创建/覆盖取实际旧文件；复用 journal 的文本和路径限制。批准绑定旧内容版本，写入前复核，预览后出现的外部修改保留。此检查不提供操作系统级原子写锁，检查与写入之间仍有很小的竞争窗口。
- 文件路径只对 Windows 本地盘符的首个冒号例外，其余选择器、通配符与策略限制保留。实际原生 Write/Edit 验证 Windows 绝对路径和 LF/CRLF 编辑。
