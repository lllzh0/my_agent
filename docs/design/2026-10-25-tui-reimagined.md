# My Agent TUI 重新设计

日期：2026-10-25。状态：交互设计候选，尚未选型或接入真实产品。

2026-10-26 更新：用户已选择“墨线”，查看[可操作 Demo](my-agent-ink-demo.html)后批准先提交基线，再接入真实 TUI。下文保留候选阶段记录。接入采用侧栏、底部输入、Ctrl+P 操作面板、F2 会话、F3 资源和独立的 `$` 技能入口；复用现有会话、资源和权限逻辑。真实终端验收另行记录，不把浏览器 Demo 的模拟执行当作实现证据。

## 已确认的设计目标

用户关注外观辨识度和操作便利，并明确不喜欢 Pi 的 TUI。新版因此同时改变布局、常用入口和内容组织。首轮方案中已有的资源控制、可核对结果和失败恢复要求继续保留。

本轮提供三套可以点击的预览。浏览某套方案或切换预览状态只表示正在比较，不代表批准实现。

## 三套方向

| 方案 | 布局与操作 | 适合场景 | 主要代价 |
| --- | --- | --- | --- |
| 墨线 | 左侧会话与能力入口，中间当前任务，结论、执行记录、文件与来源分栏切换，底部输入 | 日常编程与研究混用，频繁切会话或选技能 | 侧栏占用宽度；真实终端要明确焦点移动与窄屏折叠 |
| 纸页 | 顶部轻导航，需求输入位于结果上方，正文采用文档结构与旁注 | 长文阅读、设计讨论、研究报告 | 长结果下继续输入需要定位；终端无法照搬浏览器字号与版式 |
| 双窗 | 左侧对话和输入，右侧常驻文件、来源、执行记录与结论 | 边交流边检查修改或引用依据 | 横向空间要求最高；双区滚动和键盘焦点更复杂 |

推荐以“墨线”作为后续原型方向：它能同时给 My Agent 独立的外观和清楚的常用入口。工具、技能、会话不必依靠记忆命令才能找到。纸页可供阅读体验参考，双窗适合进一步评估宽终端下的核对流程。当前不建议同时实现并维护三套完整界面。

## 共同交互约定

- 命令与技能分开：输入 / 只显示产品命令；输入 $ 只显示当前启用的技能。选择 brainstorming 后填入 $brainstorming，再补充本次需求。
- 技能库是可见入口。导入外部技能仍需选择来源与具体项目；预览入口不执行真实导入。
- 会话切换和资源选择有可见菜单。F2 会话、F3 工具是本轮拟定快捷键，预览中可操作，不代表当前产品已提供这些按键。
- 工具面板区分文件工具、研究工具、指令和 MCP 连接；已配置与已连接分别表达。预览勾选只改变示例状态。
- 编程示例显示结果、执行记录和修改；研究示例显示结论及来源，明确区分已读正文和仅有搜索摘要。
- 请求轨迹继续使用现有 /trace 能力，默认不开正文日志。查看与对比已有记录不额外发送模型请求。
- 示例数据带有预览标识。新建会话、发送、模型选择和导入入口只说明或演示操作，不改变真实会话、配置、权限或文件。

## 真实终端的接入边界

My Agent 的会话执行、资源选择、权限判断和恢复逻辑继续复用。外观选择不要求同时更换底层运行逻辑，也不预先决定新增界面框架。

现有扩展接口已有页头、页脚、编辑器、补全和覆盖面板。墨线的常驻侧栏、双窗的独立区域需要额外布局接入，不能按换主题估算工作量。应先做最小终端原型，验证布局能力和事件流，再确定完整接入范围。

浏览器里的字号变化、阴影、间距和控件外观用于比较设计意图。真实 TUI 是按字符网格排版的终端界面，最终要使用等宽文字、颜色、粗体、空行和字符分隔线表达层级，不承诺逐像素复现。

最小原型需覆盖：

1. 窄、中、宽三种终端尺寸，中文、英文及长路径的换行和截断。
2. 中文输入法、快速粘贴、启动期输入隔离、技能补全与命令补全。
3. 键盘焦点、菜单返回、历史滚动、正文复制、窗口尺寸变化。
4. 空闲、执行中、排队补充、停止、错误、等待授权和拒绝后的状态。
5. 会话切换与恢复，以及每个会话各自的输入草稿；预览尚未完整模拟这些生命周期。
6. 实际文件变更、检查结果、来源读取范围与轨迹数据；状态取自宿主记录，不能根据模型叙述猜测成功。

## 本轮验证

三套布局已在本地浏览器中检查。已观察到示例会话切换、文件与来源面板、技能点击填入、F3 工具面板及 Esc 返回正常工作。示例页面不调用模型，也不执行系统命令。

收尾复查确认：从技能候选按 Tab 可以填入 $brainstorming；输入 $missing 显示无匹配技能；关闭再打开工具面板保留当前预览勾选。页面脚本语法检查通过，浏览器开发日志未记录错误或警告，文档空白格式检查无报错。

浏览器验证只说明预览可操作。真实终端中的渲染、中文输入法、流式输出、权限确认和会话恢复尚未验证。本轮没有替换现有 TUI，也没有形成用户验收结论。

下一步是在用户选定方向后，冻结默认布局和关键状态，制作可运行的最小终端原型。当前界面保留为开发期回退。
