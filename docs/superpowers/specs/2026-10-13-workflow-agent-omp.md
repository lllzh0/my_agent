# My Agent 的 OMP 产品入口

用户在 OMP 验证结论后要求继续，沿报告的迁移路线实施。此轮是底座和产品入口迁移，不是完整预设管理或 GUI。

## 范围和选择

在现有 fork 新增私有 workspace 包 `packages/workflow-agent`，通过 `bun run agent` 启动。它直接依赖同仓库 OMP SDK/TUI，保留父目录 Pi 原型供对照，不删除或覆盖旧源码，不提交或发布。

相比把产品逻辑散入 OMP 主包，新包使上游同步范围更小；相比仅给 OMP CLI 拼接参数，新包能落实显式资源、权限和受控工具。这一选择延续用户已同意的 OMP + Bun + 产品包装路线。

## 必须交付的行为

1. 可执行 `--help`、`setup --defaults`、`doctor`、离线演示、单轮输出和原生终端界面；默认服务仍为 OpenCode Go / DeepSeek V4.1 Flash 和 Tavily。
2. 启动器在加载 SDK 前设置独立配置目录，并建立单个工作进程。每个进程一个产品会话；新建/恢复通过重新启动处理，不能让原生会话切换复用错误的产品状态。
3. 默认不自动发现项目或全局指令、技能、扩展、MCP、自定义工具。显式文件和技能进入实际请求，未选择的代码不执行。轻量模式不带工作流资源和工具。
4. 仅开放产品明确登记的工具。读写走路径策略；写入和命令需批准；无交互批准者则拒绝副作用；命令继续走实际 macOS 沙箱，失败不裸跑。尚未适配的 `!`/Python 原生执行入口明确拒绝。
5. 迁移原型中独立于 Pi 的配置、来源/报告、修改恢复、任务和沙箱规则；用 OMP 文件工具和 SDK 接入它们。MCP 与任意第三方扩展工具的迁移不在本轮隐式启用，已配置但尚不支持的能力必须明确报错。
6. 保留会话恢复的工作区和资源签名校验、退出清理及脱敏错误。产品默认目录使用 `~/.my-agent-omp`，避免原地解释旧 Pi 会话。

## 验收、风险与回退

测试使用子进程和本地 SSE 模型服务，检查实际请求、文件副作用和保存/恢复结果。旧核心规则移入包后重跑合同测试；实测真实 PTY 和 macOS 沙箱。执行包级检查，不为本次改动运行整个 OMP/Rust 测试。

主要风险是进程级配置泄漏、原生工具旁路、会话切换时状态错配及模型协议差异。通过独立进程、固定工具清单、阻止未适配入口和真实请求测试约束。可信扩展代码仍属宿主信任边界，不声称其受到完整 OS 沙箱保护。

回退可继续使用父目录原 Pi 入口；本轮不迁移真实用户配置或会话，不使用真实 API 凭据。真实服务、完整预设切换、跨平台、独立发布包及用户六项任务验收仍单列未完成。

## 实施记录（2026-10-14）

本范围已实现并本地验证。为满足独立配置与正确终端行为，对 OMP 的 Settings 和 InteractiveMode 增加可选参数；产品通过已有原生文件写入桥检查最终文本大小。命令沙箱补上运行时 0.0.50 规则顺序所需的最后一层拒绝规则。使用说明与准确证据见 `docs/workflow-agent-migration.md`。

当前计划状态仅属于本次进程，恢复后需重新开启；菜单提供单次直接文本恢复。技能清单中的 `bodyLoaded` 仅记录产品 read 工具观察到的正文读取，不作为所有技能调用方式的完整上下文审计。这些边界保留在使用说明中。
