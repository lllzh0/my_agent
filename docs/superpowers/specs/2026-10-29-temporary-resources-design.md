# Skill 与 MCP 临时授权设计

用户已批准先提交旧工作后，按讨论方案实现 skill 与 MCP 的临时使用。起点 eae675cc32；本轮实现授权不包含新的提交、推送、真实付费服务或系统配置修改。

## 范围

普通运行提供统一的临时能力授权：既有工具、已登记 skill、已配置且有效的 MCP。候选目录来自启动时共享配置的 resources.skills 与当前预设资源；MCP 候选来自共享 mcpServers 中有效且 enabled 不为 false 的定义。只读取这些明确登记路径，不扫描其它个人目录、不安装依赖、不新增服务地址或凭据。

预设基线保持原签名，config/preset 不因临时授权改写。轻量模式不加载候选或提供申请入口。运行期授权跨同一 Host 内的新对话保留，进程退出、冷恢复、预设交接清空。

## 共用授权

提取 TemporaryAccess，namespace 为 tool/skill/mcp；共用人工审批队列、取消/版本失效、run 授权和撤销。once 不留下公共可重放凭证，只由本次具体调用继续执行。授权记录绑定资源 fingerprint（内容或连接与工具定义摘要）。auto/full 不能自动授予新资源能力；模型不能选择批准结果或期限。

保留 approveTool SDK 兼容；新增 approveResource 用于三类资源，界面沿用现有有界、脱敏、只读预览，默认选单次。权限变更、撤销、关闭或内容变化后旧审批失效。

## Skill

`$name args` 在基线已选技能时继续现有流程；未选但候选存在时询问“仅加载这次／本次运行有效／拒绝”。模型也可用 request_skill 发现并请求指定技能。审批展示名称、路径、内容摘要、理由和参数；同名不同路径拒绝歧义，不能随意挑一个。

一次加载使用批准时的不可变内容快照。复用原 Skill 与 buildSkillPromptMessage；为 Skill 增加可选 content 文本快照，不提供时保留文件读取原行为。手动临时技能沿用 native skill-prompt 消息和队列/图片处理；单次 SDK 注册只服务当前调用，在本轮结束时撤下。运行期技能出现在 `$` 列表中，每次使用校验当前内容；内容变化需重新批准。

批准技能仅允许读取该技能包内的资料，不增加包外目录或写权限；执行脚本、联网、MCP 和工具仍按原策略。单次技能包读取在本轮结束后撤下，run 在撤销后撤下。已进入聊天的正文无法由撤销抹除，界面明确说明。

## MCP

新增 request_mcp：列出候选服务，人工批准连接并检查工具目录后，才可提交具体 server/tool/arguments；工具目录发现不批准业务调用。业务临时授权绑定 server+tool，once 只运行给定参数的一次调用，run 允许该工具后续调用；不打开同服务其它工具。

复用 ManagedMcp 的连接、操作审批、脱敏、研究结果与关闭机制。为未被当前预设选择的候选服务提供临时 entry，并在 manager 的调用执行层验证授权，不能只在申请入口检查。mcp_call 工具自身关闭时仍需要工具临时授权；资源授权不默默启用该工具。原基线服务继续原行为。

临时连接在单次调用结束或取消后关闭；run 连接可复用，撤销或会话运行时关闭时释放。只关闭本次临时拥有的连接。已选服务的原连接不被其它临时请求关闭。HTTP 禁网与计划模式仍在连接前拒绝，本地 stdio 仍使用现有隔离；Windows 已知 stdio 限制不变。配置或公布的工具结构变化后旧 grant 不复用。超时或取消不自动重放。

## 管理与验证

提供 `/skills` 状态/运行期启用/撤销、`/mcp` 中临时工具入口及清晰状态；保留 `$` 调用技能、`/` 仅列命令。模型来源的管理命令拦截。

测试先失败再实现，覆盖三类共用授权隔离、技能快照与正文变化、手动 `$` 与模型请求、包内只读边界和撤销、MCP 单次/run 与其它工具拒绝、取消/连接清理/冷恢复、预设不变、工具层权限保留。只用临时目录和 localhost 模拟服务。运行全量、静态检查、独立审查及真实 Mac 终端；不以自动结果代替人工接受。
