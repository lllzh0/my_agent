# 墨线 TUI Implementation Plan

**Goal:** 将已批准的墨线 Demo 接入真实 My Agent 终端，改善外观、操作入口和结果核对。

**Architecture:** 保留 OMP 会话、输入、工具与权限控制。Composer 增加可选的有界布局装饰接口，产品层负责侧栏、标题和底部输入；产品层操作面板只调用已有受控命令。经典界面保持可启动。

**Tech Stack:** Bun、TypeScript、现有 pi-tui；不新增依赖。

**Spec:** `docs/design/2026-10-25-tui-reimagined.md`，已批准的 `docs/design/my-agent-ink-demo.html`。

## Global Constraints

- `/` 只列命令，`$` 只列技能，保留启动输入隔离。
- 状态取自真实宿主；不把模拟记录放入产品，不额外发送模型请求。
- 宽终端常驻侧栏，窄终端收起；菜单 Esc 返回，草稿保留。
- 默认折叠执行输出，可手动展开。轨迹正文默认关闭。
- 不新增依赖、自动提交或推送。用户已批准本次实现，基线为 `bef72ddd3c`。
- 风险集中在终端重排、焦点和会话切换。通过 `--ui classic` 回退；保留原会话和权限逻辑。
