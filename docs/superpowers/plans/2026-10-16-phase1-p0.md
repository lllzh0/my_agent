# 第一阶段 P0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for integration and superpowers:dispatching-parallel-agents for the three disjoint implementation domains below. Track steps with checkboxes; do not commit unless the user asks.

**Goal:** 补齐已确认的五项 P0，并增加用户主动选择的完整和自动授权。

**Architecture:** 授权、搜索、修改记录和研究各自保留小型独立模块。搜索、修改记录、研究使用互不重叠的文件并行完成；控制器负责授权、开发环境及所有入口整合。旧配置与状态保留兼容路径。

**Tech Stack:** Bun 1.3.14+、内置 SQLite、OMP 18.10.3 SDK/native search、Sandbox Runtime 0.0.50；不新增依赖。

**Spec:** `docs/superpowers/specs/2026-10-16-phase1-p0.md`

## Global Constraints

- 只改产品及必要兼容接口；无预设、GUI、真实模型请求、凭据、自动 Git 提交或推送。
- macOS arm64；普通/自动模式沙箱失败必须停止；完整模式仅用户显式选择。
- 无 any/ReturnType/动态 import；提示词静态文件；复用已有工具；禁止 source-grep 测试和 mock.module。
- 保留原 JSON，来源 ID 稳定；旧记录不是新模式授权。

## Task 1: 受控搜索

**Files:** `src/search/search.ts`、`test/search.test.ts`（均相对 `packages/workflow-agent/`）。仅此任务拥有这些文件；工具接线由控制器完成。

**Interfaces:** `Search` 构造器接收现有 Policy。公开 `find(input, signal?)`、`grep(input, signal?)`；input 支持 path/pattern、glob、literal、ignoreCase、gitignore、hidden、offset/limit，具体导出类型随实现一起报告。结果必须有 complete/truncated 和续查信息，不能把截断说成不存在。

- [x] 先写真实临时目录回归：600 个文件中后段存在唯一匹配；被忽略文件、凭据、指向外部的链接不能泄露。
  ```ts
  const response = await search.grep({ path: '.', pattern: '^LATE_[0-9]+$', glob: '*.ts' });
  expect(response.matches.some(row => row.line.includes('LATE_731'))).toBe(true);
  ```
- [x] 运行 `bun test packages/workflow-agent/test/search.test.ts`，确认因旧能力不存在/不完整而失败。
- [x] 复用 OMP native glob/grep，读取每个文件前执行 Policy 路径检查；不使用原生宽泛工具入口绕开资源和路径边界。
- [x] 验证正则、字面匹配、分页、忽略、取消、路径拒绝；把准确 API 和结果写到任务报告，供 Task 4 接线。

## Task 2: 修改记录按需存储

**Files:** `src/changes/journal.ts`、可新增 `src/changes/store.ts`、`test/journal.test.ts`；不改 undo/commands/host，接线由 Task 4 完成。

**Interfaces:** 保留 constructor/load/capture/diff/restore/restoreMany。`list()` 有界；新增 `latestTurn(): Change[]` 查询最新尚未恢复运行的完整记录，`stats()` 返回存储统计，`close()` 关闭数据库。构造器可选路径验证回调以支持完整模式外部文件；默认仍限制工作区。

- [x] 写回归：超过 100 次直接修改不再硬停；最新一次运行超过列表页大小时可完整撤销；恢复人工冲突仍拒绝。
  ```ts
  for (let n = 0; n < 105; n++) await journal.capture('one-run', target, () => Bun.write(target, String(n)));
  await journal.restoreMany(journal.latestTurn().map(change => change.id));
  expect(await Bun.file(target).text()).toBe('original');
  ```
- [x] 运行上述文件，观察旧记录上限失败；再实现 SQLite 元数据和去重快照存储、事务迁移，保留 changes.json。
- [x] 验证重启、旧格式迁移、同内容快照去重、恢复冲突、路径验证、部分失败和队列顺序。报告 API 与存储版本。

## Task 3: 来源保留与长文阅读

**Files:** `src/research/research.ts`、可新增 `src/research/store.ts`、`test/research.test.ts`、`test/source-reading.test.ts`；不改 tools/host。

**Interfaces:** 保留 Research constructor/load/search/fetch/document/report。新增 `readSource(id, options)`、`searchSource(id, query, options)`、`stats()`、`close()`。常用来源列表有界；旧引用查找走数据库而非热列表。分页按字符位置或 PDF 页码；每次结果包含返回范围、总量、续读位置和提取是否截断。

- [x] 回归：正文 12,000 字符后仍能读取；累积超过 200 个来源可以继续；热列表以外旧 ID 仍可引用；重复抓取去重但内容变更保留版本。
  ```ts
  const source = await research.document(longTextFile);
  const page = await research.readSource(source.id, { offset: 12001, limit: 1000 });
  expect(page.text).toContain('TAIL_EVIDENCE');
  ```
- [x] 本地 HTTP/真实文件证明缺失能力，再使用 SQLite 存储、正文去重、来源稳定 ID 与覆盖范围；迁移 sources.json 且保留原件。
- [x] 验证 PDF 页码、来源搜索、部分阅读状态、抓取截断、取消、旧来源、SSRF/重定向原保护。返回精确接口供 Task 4 接线。

## Task 4: 授权、开发环境及整合

**Files:** `src/policy/`、`src/config/config.ts`、`src/processes/`、`src/tui/`、`src/cli.ts`、`src/runtime/`、`src/changes/undo.ts`、静态 prompts、相关测试、README/CHANGELOG/HANDOFF。

**Interfaces:** 授权 enum `manual | auto | full`。Reviewer 输入为 Request + 用户任务 + 权限事实，输出 allow/ask/deny、风险和理由。Policy 原有方法保留；setApprovalMode 清空批准并增加版本，等待批准/审核后再次校验版本和计划状态。命令请求可显式携带 Git 写权限；Sandbox.wrap 的新增参数必须是受批准请求的范围，不能修改正在运行的其他任务。

- [x] 先写 Policy 行为回归：自动普通文件修改不弹窗；高危请求、审核超时/错误不能执行；切换模式/进入计划/取消后等待中的请求不能获得新权限。
  ```ts
  policy.setApprovalMode('auto');
  await policy.authorize({ tool: 'write', kind: 'write', target });
  expect(await Bun.file(target).exists()).toBe(false); // authorize 本身不执行工具
  // 用真实工具调用进一步验证已批准才写入，拒绝时无副作用。
  ```
- [x] 独立审核复用 OMP 现有模型客户端/判断接口；使用静态提示词，严格校验返回，不接受工具输出中的授权宣称。记录脱敏决策和额外用量。
- [x] 完整模式跳过 Path 范围限制和沙箱，但保留工具参数、快照大小、超时/取消；新会话不自动继承完整模式。`--permissions full` 和人工菜单为显式选择。
- [x] 环境变量只读取显式变量名，受控工具链和域名由配置提供，Git 写范围按请求批准，不放开其他执行配置；未知脚本不能靠安全命令前缀自动许可。
- [x] 接入 Task 1–3，调整最新轮撤销、资源关闭与来源分页工具。新增本地模型集成测试，证明 TUI/CLI 和实际副作用一致。
- [x] 产品 lint/format/types、产品测试、必要底座回归、真实沙箱组；独立只读代码审查并修复发现的问题。
- [x] 更新 HANDOFF、使用示例和未验证边界；不自动提交。用户真实服务验收仍独立。
