# 批次 3：终端进程交接

用户已明确本批为：空闲时进程交接、旧会话保存、MCP/后台清理和启动失败恢复；实现后用 env.local 的 OpenCode Go / DeepSeek V4.1 Flash max 验证。前置提交为 4ad2f31dc3，启动版真实请求基线单列，不作为交接通过证据。

Feature-change contract：launcher 通过 Bun 本机 IPC 管理会话子进程；只接收当前子进程且具有本次身份/请求号的结构化消息。新目标在无终端输入、无模型/MCP/命令调用的阶段构造完整宿主并申请会话独占；准备失败留在原进程。准备成功后保存源记录、复用原生 TUI teardown 和产品 runtime 清理，再释放终端；源退出 0 才激活目标。激活或源清理失败时关闭目标并从已保存源记录回退一次，不能恢复 full/临时授权；回退失败给出恢复命令。每阶段有限超时、取消及进程回收，取消的新目标只删除此次创建的 UUID 记录，既有恢复目标保留。

空闲门禁复用现有 sessions/SDK 状态：流式输出、已准入/排队输入、重试/压缩、BTW、review、goal、后台任务、模型/资源/会话切换均阻止；源准备期间冻结终端输入并可用 Esc 取消，禁止自动停止用户工作。当前主线不启用协作；不能声称协作分支通过。

预设和跨预设恢复共用交接，历史由用户明确选新建或恢复。新预设不套用源模型/聊天，命名会话保存模型 key、思考强度与计划模式的非秘密运行选择；legacy 兼容旧模型选择规则。资源/清单签名、目录所有权和 lease 校验保留。Win/Mac 共用 IPC/状态机，已有 Shell 和隔离适配不改。

范围：workflow-agent launcher/CLI、presets/handoff、runtime sessions/snapshot、TUI preset/resume、定向测试及文档；底座 InteractiveMode 仅增加复用现有 teardown 且不退出进程的宿主入口。禁改依赖/锁文件、隔离系统 ACL、GUI、协作分支、模型传输实现、已存在会话正文。收尾审查发现未激活目标的保存边界需要宿主回归，补入 host-worker 类型及使用/验收文档，重新限定为 36 文件、6000 行增删（原预算 32/5000）。仍为同一交接能力，无新功能或依赖。分阶段审查协议/监督、宿主/UI、回归/真实验收；超限先重新切分，不追加无关清理。
