## 范围与边界

- 只安装锁定依赖，不升级版本、不改锁文件、不关闭产品沙箱。
- 本机 HTTP 模拟模型用来捕获真实 SDK 请求，不代表远端模型质量；不读取真实密钥。
- 所有测试文件与会话放独立临时目录，不改个人配置、技能和历史。
- 若发现产品回归，先保存失败证据，再做最小修复；不进入 GUI 或预设编辑器。
- 通过现有产品检查、完整产品测试、真实系统沙箱专项及终端专项后更新证据。
- 回退只撤销本批源码/测试/文档补丁；依赖安装可重新按原锁文件准备，不删除用户数据。
